# VEDA Technology – Level 1 Day 21 | Basic SQL SELECT

A practical SQL fundamentals project completed as part of the VEDA Technology Data Analytics Track – Level 1, Day 21.

## Project Overview

The objective of this task was to build a strong foundation in SQL by writing and executing basic SELECT, WHERE, and ORDER BY queries using PostgreSQL and the Northwind sample database.

A total of 10 SQL queries were created, executed, and validated using PostgreSQL 18 and pgAdmin 4. Output screenshots for each query are included in this repository.

## Queries Implemented

### Query 1 – Display All Customers

Retrieves all columns and records from the customers table.

`SELECT * FROM customers;`

### Query 2 – Select Specific Customer Columns

Retrieves selected customer information.

`SELECT customer_id, company_name, contact_name, city, country FROM customers;`

### Query 3 – Customers from USA

Filters customers whose country is USA.

`SELECT customer_id, company_name, contact_name, city, country FROM customers WHERE country = 'USA';`

### Query 4 – Customers Ordered by Company Name

Sorts customers alphabetically by company name.

`SELECT customer_id, company_name, contact_name, city, country FROM customers ORDER BY company_name ASC;`

### Query 5 – German Customers

Filters customers from Germany and sorts them alphabetically by company name.

`SELECT customer_id, company_name, contact_name, city, country FROM customers WHERE country = 'Germany' ORDER BY company_name ASC;`

### Query 6 – Products with Unit Price Greater Than 50

Retrieves products with a unit price greater than 50 and sorts them from highest to lowest price.

`SELECT product_id, product_name, unit_price FROM products WHERE unit_price > 50 ORDER BY unit_price DESC;`

### Query 7 – Companies Containing "Market"

Uses the LIKE operator to find companies containing the word "Market".

`SELECT customer_id, company_name, contact_name, city, country FROM customers WHERE company_name LIKE '%Market%';`

### Query 8 – Products Containing "Chai"

Searches for products containing the word "Chai" and sorts them by unit price.

`SELECT product_id, product_name, unit_price FROM products WHERE product_name LIKE '%Chai%' ORDER BY unit_price DESC;`

### Query 9 – Products Priced Between 20 and 50

Uses multiple conditions with AND to filter products within a price range.

`SELECT product_id, product_name, unit_price FROM products WHERE unit_price > 20 AND unit_price < 50 ORDER BY unit_price ASC;`

### Query 10 – Customers from France

Filters French customers and sorts them alphabetically by city.

`SELECT customer_id, company_name, contact_name, city, country FROM customers WHERE country = 'France' ORDER BY city ASC;`
